# Ephemeral delivery plans

This directory is temporary working state for active implementation slices.
It is not durable project documentation.

- Delete a plan as soon as the work it describes is delivered.
- Update a plan when implementation decisions change; do not preserve it as
  history.
- Never link to or depend on these files from source code, tests, or durable
  documentation.
- When the last plan is delivered, delete this directory and remove its entry
  from the project map in `AGENTS.md`.

Git history and the delivered code are the permanent record.
